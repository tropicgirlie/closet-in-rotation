# Closet, in rotation

A small, care-first wardrobe tool for building outfits from clothes you already own. It is a personal project by Luana Micheau.

## First prototype

- Add clothing photos and optional details such as category, colour, season and comfort notes.
- Filter your closet by category and search by item name.
- Build a quick outfit from your own items.
- Keep your wardrobe in this browser. Photos are resized on your device before saving; nothing is uploaded to a server.
- Start with clearly labelled sample pieces, then replace them with your own.

## Run it

Open `index.html` in a browser. No account, server or package installation is needed.

This is a local prototype. Data lives in the browser's local storage, so clearing browser data will erase this closet. Export and import are included for backup.
