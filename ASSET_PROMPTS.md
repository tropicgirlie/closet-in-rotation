# Editorial image assets

The editorial photos in `assets/` were made with the built-in image generation tool, then optimized to WebP for this site. The supplied fashion-site screenshot was a style reference, not an edit target. The images contain no copied logos or text.

`assets/editorial-picking.webp` is an additional generated hero image. It shows a woman choosing between generic garments on a rail. The actual FARM Rio clothing in the garment edit uses images from the linked official product pages.

The current winter hero on the site uses the authentic [Barbour × FARM Rio Fall 2026 campaign](https://farmrio.eu/pages/barbour-farm-rio-fall-26) from FARM Rio Europe. The prompt below is for an original alternative image in Midjourney; it would be illustrative and should not be labelled as an actual FARM Rio product photograph.
